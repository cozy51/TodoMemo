# TodoMemo

「今すること」を1件だけ表示する、Microsoft Edge向けのシンプルな拡張機能です。

## 主な機能

- ポップアップには優先順位が一番高い未完了タスクを1件だけ表示・編集
- ポップアップでの変更は入力のたびに自動保存
- ポップアップ上部から全タスク・タグを日時付きJSONファイルへバックアップ
- 整理画面からバックアップJSONを検証・確認して復元
- タイトル、内容、任意の期限を保存
- 新しいタスクは現在の「今すること」を維持して2番目に追加
- 整理画面の1番目を「今すること」として強調表示
- 暖色系の専用拡張機能アイコン
- 内容欄でMarkdown記法を利用可能
- 内容欄ではTabでインデント、Shift+Tabでインデント解除
- インデント中に改行すると、次の行へ同じインデントを引き継ぎ
- 内容欄ではAlt+クリックでカーソルを追加し、複数箇所を同時編集
- マルチカーソル中は矢印・Home・Endで全カーソルを同時移動
- 期限までの残り日数、または期限超過日数を表示
- 期限を設定していないタスクには「期限なし」と表示
- 設定済みの期限を編集画面から削除可能
- 分類タグを作成し、タスクに複数設定
- 親案件を名前・URL（1件）付きで登録し、タスクごとにリストから選択
- 親案件バッジでは親案件名を最も大きく強調表示
- 親案件には登録年月ごとの親案件番号を、末尾 `1`～`9`、`A`～`Z`（`I`・`O`を除く）の順で自動採番（例：`TD26-07P1`、`TD26-07PA`）
- 親案件を紐づくタスクの最高優先順位で並べ、タスクがない場合は親案件番号の降順で表示
- 未完了案件を親案件ごとのグループと「親案件なし」グループで優先順位付き表示
- 親案件グループからタスク詳細への移動、または編集画面の直接表示が可能
- 親案件グループ内のタスクに設定済みの期限と残り日数を表示
- 親案件グループの見出しをクリックして、その親案件を選択済みの新規タスクを追加
- 各タスクに関連リンクを3件まで登録
- クリップボード内のURLやメールアドレスをポップアップの読む画面や編集画面から取り込み
- メール、動画、Web会議、地図、文書、SNSなどリンクの種類に応じたアイコンを表示
- 専用の整理画面でタスクを追加・編集・削除
- ドラッグ操作、上下ボタン、またはタスク編集画面のプルダウンで優先順位を変更
- 「すること」カードと親案件グループに共通の優先順位番号を表示
- 長い「すること」リストを一時的に折りたたみ、案件リンクからの移動時は自動展開
- 完了した案件カードに完了年月日と時刻を表示
- 未完了と完了を分けて管理
- データはブラウザー内の `chrome.storage.local` に保存
- ポップアップと整理画面のどちらからでも全データをJSON形式でバックアップ
- 新規タスクには登録年月ごとの案件番号を、末尾 `01`～`99`、`A0`～`Z9`（`I`・`O`・`P`を除く）の順で自動採番（例：`TD26-0701`、`TD26-07A0`）
- ポップアップと整理画面から案件番号・タイトル・内容を「案件COPY」でコピー
- 整理画面に今月から3ヶ月分の期限カレンダーと案件への移動リンクを表示
- 整理画面に優先順位・案件番号・タイトル・関連リンク・期限のコンパクト一覧を表示

## Edgeへの読み込み方

1. Edgeで `edge://extensions/` を開きます。
2. 左側の「開発者モード」をオンにします。
3. 「展開して読み込み」を選びます。
4. この `TodoMemo` フォルダーを選択します。

ツールバーのTodoMemoアイコンから「今すること」を確認できます。右上の整理アイコンを押すと整理画面が開きます。
